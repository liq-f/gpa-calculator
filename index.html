使用说明

1. 计算规则

学期平均绩点 = 本学期 Σ(学分 × 绩点) ÷ Σ学分

学年平均绩点 = 同一学年内所有学期合计 Σ(学分 × 绩点) ÷ Σ学分

总平均绩点 = 所有学期合计 Σ(学分 × 绩点) ÷ Σ学分（按学分加权，不是各学期简单平均）

勾掉某门课的「计入」即可让它不参与任何计算（体育、通识、重修前成绩等）。

只有学分、没填绩点的课程：不参与绩点计算，但会出现在「缺绩点」提示里。

2. 学年怎么划分

每个学期都有一个「学年」名字（默认：前两个学期＝大一，第三四个＝大二，依此类推）。名字相同的学期会自动汇总成一个学年，所以：

  • 想按「大一／大二／大三／大四」看，保持默认即可；
  • 想按真实学年看，把它改成 2024-2025学年 这种写法；
  • 只想按学年统计、不区分上下学期，那就一个学年只建一个学期。

顶部左侧就是各学年平均绩点，点一下可以直接跳到该学年的第一个学期。改学年名字在课程表上方的「学年」输入框里，改完立刻重算。

3. 手动录入

点「+ 添加课程」加行，直接在表格里改课程名 / 学分 / 绩点。绩点列任何时刻都能手改，支持小数（如 3.7、4.5）。

小技巧：在最后一行的输入框按 Enter 会自动新增一行；从 Excel 复制多行（带制表符）直接粘到表格里会自动拆成多门课。

4. 图片识别（OCR）

点「图片 / 文本导入」→ 选图或拖图 → 「开始识别」。首次使用需要联网下载识别引擎和中文语言包（之后浏览器会缓存，可离线再用）。

识别属于机器识别，一定会有误差：分数、学分小数点是重灾区。导入后请对着原截图核对一遍，识别不准的行会以黄色高亮提示。识别不理想时可以先在「识别原文」里改文字，再点「重新解析」，通常比重新识别更快。

截图建议：整屏截图、不要缩放糊掉、表格一行的内容尽量在同一行。

5. 成绩 → 绩点 折算（可选）

如果成绩单只有百分制分数，点学期里的「成绩→绩点」折算，只填还没有绩点的行，折算后每门课仍可手动改。

换算规则是各校自定的，可以改。点旁边的「⚙ 换算规则」按钮：

  • 内置几个常见预设（常用 4.0 制、简易 4.0 制、严格 4.0 制、5.0 制等），选一下就能套用；
  • 也可以直接改分档表：每行填「分数 ≥ 多少 → 记多少绩点」，可增删档位；
  • 规则会一直记住，OCR 识别时只认出分数、没认出绩点的课也按这套规则折算。

默认规则（常用 4.0 制）：

百分制90-10085-8982-8478-8175-7772-7468-7164-6760-63<60
绩点4.03.73.33.02.72.32.01.51.00

五级制：优=4.0、良=3.0、中=2.0、及格=1.0、不及格=0（这部分固定，不随规则变）。

6. 数据保存

所有数据只存在你这台电脑的浏览器本地（localStorage），不上传任何服务器，也不联网（OCR 除外）。

换电脑、换浏览器或清理浏览器数据会丢失记录，建议偶尔点右上角「备份」导出一份 JSON，需要时用「恢复」读回来（换算规则也会一起备份）。

「图片 / 文本导入」里的识别原文和解析结果每次重新打开都会清空，不会残留上一次的内容。

绩点公式与折算方式都可自行调整，算出来的数请以学校教务系统为准。
